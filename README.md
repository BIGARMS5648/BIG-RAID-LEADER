# BIG RAID LEADER (빅 레이드 리더)

**월드 오브 워크래프트: 포에버(World of Warcraft: Forever)** 공격대장 전용 통합 애드온입니다. (공대장 한 명만 설치해서 쓰는 구조이며, 공대원·부공대장 화면은 없습니다.)
공격대 모집부터 파티 편성, 전투 지휘, 보스 공략, **골드 경매 · 거래 자동 기록 · 골드 장부 · 골드팟 정산**까지 하나의 창에서 관리합니다.

| 항목 | 값 |
|---|---|
| 애드온 폴더 | `BigRaidLeader` |
| TOC | `BigRaidLeader.toc` (`## Interface: 16001`) |
| 명령어 | `/brl` (별칭 `/bigraidleader`, `/빅레이드`) |
| SavedVariables | `BigRaidLeaderDB` (계정 공통 설정 + 캐릭터별 설정 포함) |
| 기본 언어 | 한국어 |
| 버전 | 2.4.0 |

> **실제 게임 검증 상태**: 이 버전은 실제 WoW: Forever 클라이언트에서 실행해 보지 않았습니다.
> 게임 API를 흉내 낸 모의 환경에서 자동 테스트 132개를 통과했고(아래 참고), 실제 클라이언트에서
> 확인해야 할 항목은 [TEST_PLAN.md](TEST_PLAN.md)의 "실제 게임 테스트 체크리스트"에 정리했습니다.

## 설치

1. [`dist/BigRaidLeader-2.4.0.zip`](dist/BigRaidLeader-2.4.0.zip)을 내려받아 압축을 풉니다. (또는 이 저장소의 `BigRaidLeader` 폴더를 그대로 복사)
2. `BigRaidLeader` 폴더를 게임의 애드온 폴더에 넣습니다.
   - 포에버 클라이언트 설치 폴더 안의 `Interface\AddOns\BigRaidLeader\BigRaidLeader.toc` 위치가 되어야 합니다.
   - 설치 폴더는 배틀넷 앱에서 포에버 선택 → 옵션(톱니바퀴) → "탐색기에서 보기"로 열 수 있습니다.
3. (게임이 켜져 있었다면 완전히 종료 후) 게임을 실행하고 캐릭터 선택 화면의 **애드온** 목록에서 `BIG RAID LEADER`가 켜져 있는지 확인합니다.
   "오래된 애드온" 경고가 보이면 "오래된 애드온 불러오기"를 허용하거나, 게임 안에서
   `/run print(select(4, GetBuildInfo()))` 로 확인한 숫자로 TOC의 `## Interface:` 값을 바꾸세요.
4. 게임에서 `/brl` 을 입력하면 메인 창이 열립니다. 미니맵 버튼(동전 아이콘)으로도 열 수 있습니다.

자세한 설명: **[사용 설명서 (docs/USER_GUIDE.md)](docs/USER_GUIDE.md)**

## 주요 기능

**최우선 핵심 (골드팟)**
- **거래 자동 기록** – 거래 창 이벤트를 추적하고 `거래가 완료되었습니다` 시스템 메시지 + 실제 보유 골드 변화로
  완료를 교차 검증합니다. 창이 닫혔다는 이유만으로 완료 처리하지 않으며, 불확실한 거래는 "확인 불가"로 남겨
  수입에 합산하지 않습니다. 이벤트 중복/순서 변경/UI 재시작에도 이중 기록되지 않습니다.
- **골드 경매** – 아이템 링크 등록(Shift+클릭/드래그/전리품 창), 대기열·순서 변경, 시작가·최소 증가액·즉시 낙찰가,
  채팅 입찰 자동 인식(금액만 입력) + 수동 입찰, **카운트 5초 / 카운트 취소**, 막판 연장, 낙찰 확정, 유찰/재경매/취소, 공대장 본인 낙찰금 "본인 지급" 기록.
- **경매와 실제 거래 연결** – 낙찰액(예정)과 실제 수금액을 분리. 부분/합산/일괄/대리 입금, 초과 입금 경고,
  중복 연결 방지, 낙찰 취소 시 환불 추적. 자동 매칭은 **제안만** 하고 확정은 공대장이 승인합니다.
- **거래 보조** – 거래 창 옆 정보 패널(상대에게서 받을 낙찰금/줄 분배금과 거래 창 금액 실시간 비교, [분배금 입력]은 골드 칸만 채우고
  수락은 직접), 아이템 거래의 가방 수량 교차 검증, 최근 거래 10건 이벤트 추적(판정 근거)
- **구매자 기록** – 모든 세션의 구매자별 구매 수·총액·평균·최고가
- **연속 경매** – 낙찰/유찰 후 N초 뒤 다음 대기 경매 자동 시작(전투 중 보류, 취소 가능)
- **골드 통합 장부** – 수입/지출 분류, 미지급금, 장부 잔액, 수동 기록(사유 필수), 수정 이력, CSV 내보내기.
- **골드팟 자동 정산** – 정수 코퍼 계산(오차 0), 예상/확정 정산 구분, 균등 분배(기본) + 제외/수수료/역할·고정·비율
  보너스/수동 금액, 코퍼·실버·골드 단위 분배와 잔돈 보관·이월, 파티별 정산(인원이 다른 파티 포함), 대표 수령,
  지급 상태(지급 전/부분/완료/확인 필요/보류), 합계 항등식 검증, 확정 잠금과 버전 관리.
- **정산 보고서** – 상세/간략/디스코드 형식, 255바이트 자동 분할 채팅 출력, 버전별 보관.

**공격대 운영**
- **구성 분석 · 추천 직업** – 20인/40인 최적 직업 구성 기준으로 현재 없는 공격대 버프·파티 버프·보스 약화·공격대 생존기·유틸리티를
  실시간 계산하고, 더 데려와야 할 직업(역할 포함)을 순위와 이유로 추천. 남은 자리 구성안, 모집 정원 자동 반영, 모집 문구 `{recommend}`
- **전투 준비(도핑 점검)** – 버튼 한 번으로 음식·영약/비약·필수 버프가 없는 공대원을 결과 창으로 표시, 공격대 공지/개별 귓속말
- **풀링 판정** – 준비 확인·사망/부재·도핑·역할을 종합해 "풀링 가능 / 주의 후 풀링 / 풀링 보류"와 사유 표시(보류 시 풀링 전 확인)
- **보스 준비 적용** – 보스 선택 한 번으로 현재 보스 지정 + '보스:이름' 편성 템플릿 불러오기 + 전술표/징표/메모/필수 버프 화면 전환
- **전멸 복구** – 우두머리 전투 실패 후 전투가 끝나면 사망자·영혼석 보유자·재버프 필요·도핑 누락을 자동으로 보여줌
- **공대장 HUD** – 메인 창 없이 경매/카운트, 거래 상대 정보, 풀링 판정, 도핑, 미지급을 보여주는 작은 창 + 카운트/취소 버튼과 지휘 명령(준비 확인·풀링·풀링 취소·공격 중지·후퇴·재정비·휴식·공략 안내·전투 준비)
- **공유 문자열** – 공략(배치도·타임라인)/파티 편성/전술표를 체크섬 문자열로 주고받기
- 공격대 모집(템플릿, 직업/역할 정원, 클릭 전송, 귓속말 지원자 대기열·승인·거절·보류·중복 확인, 재모집 안내)
- 공대원 관리(직업/역할/파티/접속/사망/공대장·부공대장 표시, 정렬·검색, 부족 역할 경고)
- 파티 편성(8×5 슬롯 클릭/드래그, 자동 편성 제안, 고정 인원, 템플릿, 전투 중 차단된 단계별 실제 적용)
- 역할·전술 임무(13종 임무, 차단/해제/탱커 교대/생존기/기믹 순서표 + 예비, 담당자 교체, 중복 배정 검증)
- **전투 준비 화면**: 준비 확인(준비/미응답/오프라인/사망/미입장/내구도/도핑) + 버프·도핑·**포에버 야영지 효과**(직업 버프 대체 관계, 담당자, 만료 경고, 전멸 후 재점검) + 필수 버프
- 전투 지휘(지휘 명령 버튼은 HUD: 준비 확인, 공식 풀링 카운트다운, 공격 중지/후퇴/재정비/휴식 · 전투 지휘 화면: 커스텀·저장 명령, 단축키)
- 공격대 징표(보안 버튼 징표 바, 월드 징표)
- 보스 공략(지하 심굴·하이잘 정상·오닉시아의 둥지, 편집 가능, 전술 배치도, 수동 타임라인, 진행/시도/전멸/처치 시간)

**화면**
- 블랙 팬서 테마: 원형 표범 미니맵 아이콘(게임 기본 미니맵 테두리), 무채색 모던 스타일(평면 버튼·흰 주요 버튼·사이드바 메뉴·로우폴리 머리 띠), 모든 화면 겹침/잘림 자동 검사

**관리 · 안정성**
- **자가 진단** (`/brl 진단`, 설정 > 진단) – API/이벤트 지원, 거래 기록 상태, 저장 데이터 무결성, 정산 잔액 검증, 오류 기록을 한 번에 점검해 복사
- 하루 1회 자동 백업, 무결성 검사, 전체 백업 문자열, 설정 내보내기/가져오기

## 권한

이 애드온은 **공격대장 전용**입니다.

| 상태 | 할 수 있는 일 |
|---|---|
| 공격대장 (그룹 안) | 모든 기능 |
| 그룹 밖 | 사전 준비(경매 등록·편성 계획·공략 편집)와 해산 후 정산·지급 기록 (세션을 만든 캐릭터만) |
| 부공대장 / 공대원 | 운영 기능 잠김 (내 데이터 열람·백업만 가능) |

권한은 게임 API(`UnitIsGroupLeader`)로만 판단하며, 확인할 수 없으면(Secret Value 등) 편집이 잠깁니다.
다른 공대원에게 애드온 설치를 요구하지 않으며, 애드온 간 통신(애드온 메시지)도 사용하지 않습니다.

## 골드팟(GDKP) 정책

블리자드는 WoW: Forever의 GDKP(골드팟)를 금지했고, 이후 보도에 따르면 금지 대상은 북미/유럽 서버입니다.
**한국 서버 적용 여부는 개발 시점(2026년 11월)에 공식 확인되지 않았습니다.** 골드 경매를 운영하기 전에 블리자드 공식 공지와 이용약관을 확인하세요.
이 애드온은 현금 거래·골드 구매·게임 밖 거래를 지원하지 않으며, 내 캐릭터의 정상적인 게임 내 거래만 기록합니다.

## 알려진 제한 사항 (요약)

- 실제 포에버 클라이언트에서 검증하지 않음 (모의 환경 자동 테스트만 수행)
- 지하 심굴/하이잘 정상 우두머리 이름·기술은 공식 미공개 → "미확인" 표시, 인게임 편집/전투 이벤트로 갱신
- 우두머리 전투 중(채팅 잠금) 채팅 입찰 인식 불가 → 수동 입찰, 잠금 해제 후 공지 자동 전송
- 다른 공대원의 마법부여/저항/시약/내구도는 API로 확인 불가 (표시하지 않음)
- 거래 창 [분배금 입력](`SetTradeMoney`)은 클라이언트가 막으면 골드를 직접 입력하라는 안내로 대체
- 우편/경매장 골드는 자동 기록되지 않음 → 장부 수동 기록
- 자세한 목록: [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md#알려진-제한-사항)
