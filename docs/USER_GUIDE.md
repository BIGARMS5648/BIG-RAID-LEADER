# BIG RAID LEADER 사용 설명서

월드 오브 워크래프트: 포에버 공격대장 전용 통합 애드온 **BIG RAID LEADER(빅 레이드 리더)** 의 설치 방법과 기능별 사용법입니다.
공대장 한 명만 설치해서 사용하며, 공대원에게 애드온 설치를 요구하지 않습니다.

---

## 1. 설치

### 1.1 설치 순서
1. 배포 ZIP(`BigRaidLeader-2.2.0.zip`)의 압축을 풉니다. 안에 `BigRaidLeader` 폴더가 하나 있습니다.
2. 배틀넷 앱에서 포에버를 선택 → 옵션(톱니바퀴) → **탐색기에서 보기**로 설치 폴더를 엽니다.
3. 설치 폴더 안의 `Interface\AddOns\` 에 `BigRaidLeader` 폴더를 넣습니다. (폴더가 없으면 만드세요)
   - 올바른 위치: `…\Interface\AddOns\BigRaidLeader\BigRaidLeader.toc`
   - 잘못된 위치: `…\Interface\AddOns\BigRaidLeader\BigRaidLeader\BigRaidLeader.toc` (폴더가 한 번 더 들어간 경우)
4. 게임을 시작하고 캐릭터 선택 화면 왼쪽 아래 **애드온** 버튼에서 `BIG RAID LEADER` 를 켭니다.
5. 접속 후 채팅창에 `[BRL] v2.2.0 로드됨` 메시지가 보이면 설치 완료입니다.

### 1.2 "오래된 애드온"으로 표시될 때
TOC 의 Interface 번호(16001)가 클라이언트와 다르면 오래된 애드온으로 표시됩니다.
- 애드온 목록에서 **오래된 애드온 불러오기**를 체크하거나,
- 게임에서 `/run print(select(4, GetBuildInfo()))` 를 입력해 나온 숫자로 `BigRaidLeader.toc` 첫 줄 `## Interface:` 값을 바꿉니다.

### 1.3 데이터 위치
데이터는 로그아웃/UI 재시작(`/reload`) 시 `WTF\Account\<계정>\SavedVariables\BigRaidLeader.lua` 에 저장됩니다.
게임이 비정상 종료되면 마지막 저장 이후 기록이 사라질 수 있으니, 정산 직후 `/reload` 를 한 번 해 두면 안전합니다.

## 2. 기본 사용

| 동작 | 방법 |
|---|---|
| 메인 창 열기/닫기 | `/brl`, 미니맵 버튼 좌클릭, 단축키(키 설정 > 애드온 > BIG RAID LEADER) |
| 경매 화면 바로 열기 | 미니맵 버튼 우클릭, `/brl 경매` |
| 메뉴 바로 열기 | `/brl 정산`, `/brl 거래`, `/brl 편성` … |
| 창 이동/크기 | 제목 표시줄 드래그 / 오른쪽 아래 모서리 드래그 |
| 공대장 HUD | `/brl hud`, 대시보드 [HUD], 단축키 |
| 도움말 | `/brl 도움말` |

### 2.1 화면 구성
- **제목 표시줄**: 현재 **공격대 세션** 선택, 권한 상태(공격대장 / 그룹 밖 / 공대장 아님·잠김), 전투 중 표시
- **왼쪽 메뉴**: 13개 메뉴. `거래 로그` 옆 숫자는 확인이 필요한 거래 수, `전리품 경매` 옆 "진행"은 경매 진행 중
- **아래 상태 표시줄**: 진행 중인 거래, 채팅 제한 상태, 확인 불가 거래 수

### 2.2 공격대 세션
경매·거래 연결·장부·정산은 **공격대 세션** 단위로 관리합니다.
- 제목 표시줄 드롭다운 → **+ 새 공격대 세션** (공격대 선택 + 이름)
- 경매 아이템을 처음 등록할 때 세션이 없으면 자동으로 만들어집니다.
- 세션에는 그 시간 동안 공격대에 있었던 **참가자**가 자동 기록되며, 정산 분배 대상의 기본값이 됩니다.
- 세션을 만든 캐릭터가 그 세션 장부의 최종 책임자입니다.

### 2.3 슬래시 명령
```
/brl                      메인 창
/brl <메뉴>               대시보드 모집 공대원 편성 역할 준비 버프 야영지 지휘 공략 경매 거래 장부 정산 설정
/brl 경매 [링크] [시작가]   경매 등록 (예: /brl 경매 [천둥분노] 500)
/brl 입찰 <이름> <금액>     진행 중인 경매에 수동 입찰
/brl 카운트 / /brl 카운트취소  경매 카운트(기본 5초) 시작 / 취소
/brl 준비                  준비 확인
/brl 전투준비 (/brl 도핑)    도핑(음식/영약/비약) 점검 결과 창
/brl 구성 [10|20|40]        구성 분석 결과(없는 시너지·추천 직업)를 채팅창에 표시
/brl 풀 [초]               풀링 카운트다운
/brl 세션 [이름]           새 공격대 세션
/brl 백업                  데이터 백업
/brl 진단                  자가 진단: API·이벤트·무결성·오류 기록 (문제 보고용, /brl 검사·/brl 호환성도 같음)
/brl 추적                  최근 거래 10건 이벤트 추적
/brl hud                   공대장 HUD 열기/닫기
/brl 판정                  풀링 판정 결과를 채팅창에 표시
/brl 복구                  전멸 복구 점검 (사망자·영혼석·재버프·도핑)
/brl 보스준비              현재 보스 준비 적용
```

### 2.4 금액 입력 방법
금액 칸에는 다음 형식을 모두 쓸 수 있습니다. 내부 계산은 모두 **정수 코퍼**(1골드 = 10,000코퍼)입니다.
- `2500` → 2,500골드 / `2,500` → 2,500골드
- `2500g 30s 5c`, `2500골드 30실버 5코퍼`
- `2.5k` → 2,500골드 / `3천` → 3,000골드 / `1.2만` → 12,000골드

## 3. 골드팟 운영 흐름 (권장 순서)

1. **세션 만들기** – 공격대 시작 시 새 세션 (공격대 종류 선택)
2. **경매 등록** – 전리품 경매 > 아이템 등록 (Shift+클릭, 드래그, 전리품 창에서 가져오기)
3. **경매 진행** – 다음 경매 시작 → 공대원은 공격대 채팅에 금액만 입력 → 마감 → **낙찰 확정**
4. **수금** – 낙찰자와 거래 (아이템을 건네고 골드를 받음). 거래 창 옆 **정보 패널**에 상대에게서 받을 낙찰금과 넣은 골드 비교가 보입니다
   → 거래 직후 분류 창에서 **제안대로 연결** 또는 **경매금 수금**
5. **정산** – 골드 정산 > 정산 만들기 → 설정(운영비/수수료 등) 확인 → **정산 확정(잠금)**
6. **분배 지급** – 공대원과 거래 → 정보 패널 **[분배금 입력]** 으로 골드 칸 채우기(수락은 직접) → 분류 창에서 **분배 지급** 연결
7. **보고서** – 간략 보고서 채팅 출력, 디스코드용 복사
8. **정산 종료** – 미지급금 0 확인 후 정산 종료 (남아 있으면 경고 후 기록 유지)

## 4. 기능별 사용 방법

### 4.1 대시보드
공격대 이름·인원·탱커/힐러/딜러 수·부족한 역할·준비 확인·현재 보스·진행률·경매 총액·실제 수금액·분배 가능 골드·
미지급금·정산 상태·장부 잔액·확인 필요 거래·파티별 인원을 타일로 보여 줍니다. **타일을 클릭하면 해당 화면으로 이동**합니다.
아래 **빠른 실행**에서 준비 확인, 풀링(판정이 보류면 확인 후), 전투 준비, 다음 경매 시작, **지난 세션**(세션 목록·전환), 징표 바, **풀링 판정**, **HUD** 를 바로 실행합니다.
"보스 진행" 타일을 누르면 보스 공략 화면(진행 탭)으로 이동합니다.
오른쪽 **진행 현황**은 현재 경매(최고 입찰/카운트), 모집 진행, 풀링 판정, 마지막 도핑 점검, 분배 지급 진행, 진행 중 거래를 한눈에 보여 줍니다.

### 4.2 공격대 모집
- 화면 위쪽 탭: **모집 공고** / **구성 분석 (추천 직업)**
- 공격대 선택 → 역할별/직업별 **모집 정원** 입력 → 모집 문구 편집 (치환: `{raid}` `{size}` `{have}` `{need}` `{recommend}` `{roles}` `{note}`)
  - `{recommend}` 는 구성 분석의 상위 추천 직업 3개로 바뀝니다 (예: `우대: 주술사(근딜), 드루이드(힐러), 흑마법사(원딜)`).
    전송할 때마다 그 시점의 공격대 구성으로 다시 계산됩니다.
- 채널(길드/일반/외치기/참여 중인 채널) 선택 후 **모집 문구 전송** – 게임 정책상 클릭할 때마다 한 번만 전송됩니다.
- 모집 중에는 귓속말("1", "참", "힐 가능", "법사" 등)을 보낸 사람이 **지원자 대기열**에 자동 추가됩니다.
  직업/역할 키워드를 자동 인식하고, 같은 사람이 다시 보내면 "중복"으로 표시합니다.
- 지원자 선택 → **승인(초대)** / 거절 / 보류 / 삭제. 초대는 버튼 클릭으로만 이루어집니다.
- **모집 종료 공지**로 마감, 공대원이 빠지면 재모집 안내가 표시됩니다. 자주 쓰는 설정은 템플릿으로 저장하세요.
- 진행 상황 아래에 **추천 추가 직업**이 실시간으로 표시됩니다.

#### 구성 분석 (추천 직업) 탭
20인/40인(및 10인) **최적 직업 구성**을 기준으로, 지금 공격대에 없는 시너지와 생존기를 계산해 더 데려와야 할 직업을 알려 줍니다.
공대원이 들어오거나 나가면 바로 다시 계산됩니다.
- **기준 인원**: 10/20/40인 (기본값은 모집 템플릿의 공격대 인원)
- **포함**: 현재 공대원만 / 공대원 + 승인한 지원자 / 공대원 + 모든 지원자 → 초대 전에 "이 사람을 받으면 무엇이 채워지는지" 미리 볼 수 있습니다.
- **시너지 목록** (분류 필터, "부족한 것만" 체크):
  | 분류 | 예 |
  |---|---|
  | 공격대 버프 | 신의 권능: 인내, 신비한 지능, 야생의 징표, 성기사 축복(40인 기준 4명), 천상의 정신, 암흑 보호 |
  | 파티 버프 | 전투의 외침, 질풍의 토템, 마나샘 토템, 대지력의 토템, 무리의 우두머리, 정조준 오라, 달빛야수 오라, 성기사 오라, 피의 서약, 흡혈의 선물 |
  | 보스 약화 | 방어구 가르기, 흑마법사 저주(무모함/원소/어둠), 요정의 불꽃, 성기사 심판, 천둥벼락/사기의 외침, 화염 취약, 암흑의 그물 |
  | 공격대 생존기 | 전투 부활(환생), 영혼석, 정신 자극, 마나 해일 토템, 진동의 토템, 공포의 수호물, 탱커 생존기, 광역 도발, 신의 중재, 보호의 축복, 평온 |
  | 유틸리티 | 주문 차단, 저주 해제, 마법 해제, 독/질병 해제, 생명석, 소환 의식, 평정의 사격, 군중제어 |
  - 상태: **확보** / **부족**(예: 2/3) / **없음** / **야영지 대체**(해당 야영지 시설이 준비됨) / **직업 제한**(사용 불가 직업만 제공)
  - **파티 버프**는 수혜자가 있는 파티마다 제공자가 필요하므로, 수혜 인원 4명당 1파티로 필요한 제공자 수를 계산합니다
    (예: 근접 12명 → 질풍의 토템 주술사 3명). 주술사 1명은 질풍/마나샘 중 한 파티만 담당하는 것으로 계산합니다.
  - 마우스를 올리면 제공 직업(`*` = 특성/전문화 필요), 수혜 인원, 대체 야영지를 보여 줍니다.
- **추천 추가 직업**: 한 명을 추가했을 때 가장 많이 채워지는 직업 순서와 그때 확보되는 시너지(예: `주술사 근딜 – 질풍의 토템, 진동의 토템`).
  역할(탱커/힐러/근딜/원딜)도 함께 추천합니다. 중요도(핵심 3 > 중요 2 > 있으면 좋음 1), 역할 목표(탱커·힐러 우선), 목표 직업 구성을 함께 고려합니다.
- **남은 자리 추천 구성안**: 남은 자리를 모두 채울 때의 직업/역할 조합과, 채운 뒤에도 부족한 항목 수.
- **현재 파티 배치에서 빠진 파티 버프**: 공격대 상태이면 "2파티 전투의 외침" 처럼 표시 → 파티 편성에서 재배치하세요.
- 버튼:
  - **추천을 모집 정원에 반영** – 직업별 정원 = 현재 인원 + 추천 추가 인원, 역할 정원 = 목표 역할 구성
  - **분석 결과 출력** – 없는 버프/부족한 생존기/추천 직업을 공격대·길드 채팅 또는 복사 창으로
  - **사용 불가 직업** – 진영/서버 사정으로 모집할 수 없는 직업 제외
  - **목표 구성 편집 / 목표 역할 편집 / 기본값** – 기본 최적 구성(오리지널 공격대 메타)을 바꿀 수 있습니다

| 기본 목표 구성 | 전사 | 사제 | 성기사 | 주술사 | 드루이드 | 마법사 | 흑마법사 | 도적 | 사냥꾼 | 역할 (탱/힐/근/원) |
|---|---|---|---|---|---|---|---|---|---|---|
| 20인 | 3 | 3 | 2 | 2 | 2 | 2 | 2 | 2 | 2 | 2 / 5 / 6 / 7 |

### 4.6 전투 준비 (준비 확인 · 버프 · 야영지)
예전 "준비 상태"와 "버프 및 야영지" 메뉴를 합친 화면입니다. 탭: **준비 확인 / 버프·도핑 / 야영지 효과 / 필수 버프/담당자**

**준비 확인 탭**
- **준비 확인 시작** → 준비 완료/준비 안 됨/미응답/오프라인, 사망, 인스턴스 미입장, 내구도를 표시합니다.
- 내구도는 게임 API로 본인 장비만 확인할 수 있습니다. 마법부여·저항 장비·시약은 다른 공대원 상태를 볼 수 없어 표시하지 않습니다.
- **도핑** 열: 마지막 [전투 준비] 점검 결과(완료 / 누락 항목 / 확인 불가)를 보여 줍니다.
- **결과 채팅 출력**으로 미응답/사망/미입장/내구도 낮음 인원을 알립니다. [풀링 판정] 버튼도 여기 있습니다.

#### 전투 준비 (도핑 점검)
**[전투 준비]** 를 누르면 공대원 전원의 버프를 다시 읽어 **누가 음식·영약/비약(·필수 버프)이 없는지** 바로 알려 줍니다.
- 버튼 위치: 대시보드 빠른 실행, 전투 준비 화면, HUD, 단축키(키 설정 > 애드온 > 전투 준비), `/brl 전투준비` (또는 `/brl 도핑`)
- 결과 창: 파티·이름·음식·영약·비약 수·상태(누락/곧 만료/확인 불가). "누락/확인 불가만 보기"가 기본입니다.
  - **공격대에 알리기**: `[BIG RAID LEADER 전투 준비] 도핑 완료 15/20 / 음식 없음(2): A, B / 영약/비약 없음(3): C, D, E / 곧 만료: F(음식 3분)`
  - **누락자 귓속말**: 각자에게 `[BRL 전투 준비] 필요: 음식, 영약/비약`
  - **준비 확인**, **다시 점검**, **복사**
- 판정 기준 (설정 > 일반 > 전투 준비):
  - 음식 버프 필수 (기본 켬)
  - 영약/비약 기준: **영약 또는 비약**(기본) / 영약 필수 / 비약 필수(최소 개수) / 점검 안 함
  - 필수 직업 버프도 함께 점검 (기본 켬, 전투 준비 > 필수 버프/담당자 탭 설정 사용)
  - 곧 만료(버프 만료 경고 분 기준)도 누락으로 알림 (기본 끔)
  - 전투 준비 시 공격대 채팅 자동 공지 / 준비 확인 함께 실행 (기본 끔)
- 음식은 '포만감' 외 이름의 음식 버프도 주문 ID로 인식합니다. 포에버의 실제 버프 이름이 다르면 **설정 > 버프 키워드 보완**에서 음식/영약/비약 키워드를 추가하세요.
- 전투 중에는 점검할 수 없고, 오프라인/Secret Value 인원은 "확인 불가"로 따로 표시됩니다. 물약·주문서처럼 사용하면 사라지는 소모품은 점검할 수 없습니다.

#### 풀링 판정
준비 확인 · 사망/부재 · 도핑 · 역할을 종합해 **풀링 가능 / 주의 후 풀링 / 풀링 보류** 와 사유를 보여 줍니다.
- 보류: 사망자, 준비 안 됨 / 주의: 준비 확인 미실시·무응답·5분 지남, 오프라인·다른 지역, 도핑 점검 안 함·10분 지남·누락, 필수 버프 누락,
  탱커 미지정·힐러 없음, 전멸 후 재점검 필요, 내 장비 내구도 낮음
- 위치: 대시보드(빠른 실행 + 진행 현황), 전투 준비 화면·결과 창, HUD, 단축키, `/brl 판정`
- 판정이 **보류**일 때 [풀링] 버튼을 누르면 사유를 보여 주고 "그래도 풀링"을 확인한 뒤 시작합니다. (최종 판단은 공대장)

#### 전멸 복구
우두머리 전투가 실패(전멸)하면 **전투가 끝난 뒤 자동으로** 정비 점검 창이 뜹니다 (설정 > 일반 > 전투 준비에서 끌 수 있음).
- **사망자** 목록, **영혼석 보유자**(사망자 중 자가 부활 가능 인원 강조), **재버프 필요**(버프 담당자 표시), 도핑 누락
- [복구 순서 공지]: `부활 → 재버프 → 도핑 → 준비 확인` 순서와 대상을 공격대 채팅으로 알립니다.
- 직접 실행: `/brl 복구`. 영혼석 버프 이름이 다르면 설정 > 버프 키워드 보완에 `SOULSTONE` 키워드를 추가하세요.

### 4.7 전투 준비 > 버프·도핑 / 야영지 / 필수 버프 탭

- **필수 버프/담당자** 탭: 공통 필수 버프, 보스별 필수 버프(오른쪽 위에서 보스 선택), 버프 담당자 지정/자동 지정.

### 4.10 전리품 경매
**골드 경매 탭**
- 아이템 등록: **아이템 등록** 버튼(시작가/최소 증가액/즉시 낙찰가/시간), 아래 입력칸에 Shift+클릭 후 Enter,
  **전리품 창에서**(전리품 창이 열려 있을 때). 같은 아이템 중복 등록 시 확인을 받습니다.
- 대기열: ▲▼ 순서 변경, 시작(또는 더블클릭), 수정, 취소, 재경매(유찰/취소/낙찰 취소 건)
- 진행: **다음 경매 시작** → 공격대 경보로 시작 공지 → 공대원은 **금액만** 입력(`1500`, `1500골드`, `1.5k`, `입찰 1500`)
  - 최소 입찰가 미달, 같은 금액(먼저 입찰한 사람 우선), 공대원이 아닌 사람의 입찰은 거부되어 입찰 내역에 사유와 함께 남습니다.
  - 귓속말 입찰이 거부되면 사유를 귓속말로 알려 줍니다.
  - 남은 시간이 카운트 초(기본 5초) 이하가 되면 [카운트]와 같은 형식으로 자동 카운트, 막판 입찰 연장(설정), 즉시 낙찰가 도달 시 자동 마감
  - 입찰 방법 안내(`입찰은 공격대 채팅…`)는 세션의 첫 경매(또는 30분 만)에만 나갑니다.
- **카운트 5초 / 카운트 취소**: 입찰이 잦아들면 **[카운트 5초]** 를 누르세요. 공격대 경보로
  `[카운트] [아이템] 최고 ○○ 1,500골드 - 5` → `4` → `3` → `2` → `1` 을 공지하고 입찰을 마감합니다.
  - **[카운트 취소]**: 카운트를 멈추고 `[카운트 취소] 입찰 계속` 을 공지합니다. 남은 시간은 원래 시간과 10초 중 긴 쪽으로 돌아갑니다.
    시간 만료 직전의 자동 카운트다운도 같은 버튼으로 취소할 수 있습니다.
  - 카운트 중 새 입찰이 들어오면 자동으로 카운트가 취소되고 `[카운트 취소] 새 입찰 바람검 1,600골드 (다음 최소 1,650골드) - 입찰 계속`
    한 줄만 공지합니다(최고 입찰 공지를 겸함)
    (설정 > 경매/정산 > "카운트 중 새 입찰 시 카운트 취소"로 끌 수 있음).
  - 카운트 초는 설정 > 경매/정산 > 카운트(초)에서 3~10초로 바꿀 수 있습니다 (기본 5초).
  - 단축키: 키 설정 > 애드온 > 경매 카운트 / 경매 카운트 취소 · 명령어: `/brl 카운트`, `/brl 카운트취소`
- **공대장 본인 입찰**: 공대장도 공격대 채팅에 금액을 쓰거나 수동 입찰로 직접 입찰할 수 있습니다.
- **연속 경매**: [연속 경매]를 체크하면 낙찰 확정/유찰 후 대기 시간(기본 8초, 설정 > 경매/정산) 뒤 다음 대기 경매가 자동으로 시작됩니다.
  `[경매] 다음 경매 8초 후 시작: [아이템] (남은 3건)` 을 공지하며, [자동 시작 취소]로 멈출 수 있습니다. 전투 중에는 자동 시작하지 않습니다.
- **낙찰 확정**: 마감 후 공대장이 확인하고 확정합니다. **다른 입찰로 낙찰**, **입찰 철회**, 유찰, 경매 취소 가능.
- 우두머리 전투 중(채팅 제한)에는 채팅 입찰을 인식할 수 없으니 **수동 입찰**을 사용하세요.

**낙찰·수금 탭**
- 낙찰별 낙찰액·수금·상태(수금 전/부분 입금/완납/초과 입금/환불 필요)·아이템 전달 여부
- **수금 거래 연결**(또는 더블클릭): 완료된 거래를 골라 금액을 연결 → 부분 입금, 여러 거래 합산, 다른 사람의 대리 입금 가능.
  낙찰금보다 크면 초과 입금 경고 후 기록합니다.
- **연결 내역/해제**, 전달 표시, 금액 수정(사유), **낙찰 취소**(이미 받은 금액은 환불 필요로 표시) → 환불 거래를 연결하면 정리됩니다.
- **본인 낙찰금 기록**: 공대장이 직접 낙찰받으면 거래할 상대가 없으므로, 낙찰 확정 직후 "지금 기록할까요?" 창이 뜹니다
  (나중에 이 버튼으로도 가능). 기록하면 본인 지갑의 골드를 공대 금액으로 낸 것으로 **거래 로그에 "본인 지급"** 이 남고,
  낙찰 수금에 연결되어 실제 수금액·장부 수입·정산 총수입에 포함됩니다. 아이템은 이미 본인에게 있으므로 전달 완료로 표시됩니다.
  잘못 기록했으면 [연결 내역/해제]로 연결을 해제한 뒤 거래 로그에서 해당 기록을 취소하세요.
- 결과 공지
- 경매 낙찰금은 낙찰 직후 거래로 받는 것을 전제로 하므로 미수금 관리(독촉·입찰 제한·미수금 표시) 기능은 없습니다.

**구매자 기록 탭**: 모든 세션의 낙찰을 구매자별로 모아 구매 수·총 구매액·평균·최고·참여 세션 수·최근 구매를 보여 줍니다.
구매자를 선택하면 구매 내역(아이템/금액/세션)이 표시되고, **구매 내역 복사**를 할 수 있습니다.


### 4.11 거래 로그
- 내 캐릭터의 모든 거래가 자동 기록됩니다: 시각, 거래 상대, 받은 골드, 지급 골드, 아이템, 거래 목적, 연결, 상태
- **상태**: 완료 확인 / 확인 불가 / 취소 / 수동 확인 / 본인 지급(공대장 본인 낙찰금) / (수동 조정) / 기록 취소. **완료 확인·수동 확인만** 금액에 합산됩니다.
- **거래 목적**: 경매금 수금, 공대원 골드 분배, 공대장 개인 거래, 기타 공대 지출, 기타 공대 수입, 경매금 환불, 분류되지 않은 거래.
  개인 거래와 미분류 거래는 공대 장부에 들어가지 않습니다.
- 필터: 골드팟 관련/개인/확인 불가/미분류/취소, 입금/출금, 골드/아이템 거래, 기간(오늘/7일/30일/현재 세션), 거래 상대, 메모/아이템 검색
- 우클릭(작업 메뉴): 상세/수정 이력, 목적 변경, 경매금/분배/환불 연결, **연결 제안 승인**, **수동 확인**(확인 불가 거래를 직접 확인했을 때만),
  취소로 표시, **금액 정정**(원본은 보존, 사유 필수), 메모, 기록 취소/복원
- **수동 기록 추가**: 자동 기록되지 않은 거래를 사유와 함께 추가합니다. 수동 기록은 자동 기록과 구분됩니다.
- **거래 직후 분류 창**: 거래가 완료되면 작은 창이 떠서 한 번의 클릭으로 경매금 수금/분배 지급/개인/기타 수입·지출로 분류합니다.
  낙찰자와의 거래이면 "제안: ○○ 낙찰금 … (금액 일치)" 처럼 제안이 표시되며, **제안대로 연결**을 눌러야 반영됩니다.
- 거래 완료 귓속말(설정에서 켬): `[BIG RAID LEADER 거래 완료] 상대방 / 아이템 / 받은 골드 / 거래 시각`
- **완료 검증 방식**: 완료 메시지 + 골드 변화 일치 / 완료 메시지 + 가방 아이템 변화 일치 / 골드 변화 일치(메시지 누락) /
  가방 아이템 변화 일치(메시지 누락) 등이 상세·툴팁에 표시됩니다. 아이템만 오간 거래는 수락 시점의 가방 수량과 거래 후 수량을 비교해 판정합니다.
- **이벤트 추적**: 최근 거래 10건(기록되지 않은 빈 거래 포함)의 이벤트 순서(창 열림 → 수락 → 완료 메시지 → 창 닫힘 → 골드/가방 변화 → 판정)와
  판정 근거를 보여 줍니다. 거래가 잘못 기록되면 이 내용을 복사해 알려 주세요. (`/brl 추적`)

#### 거래 창 정보 패널
거래 창이 열리면 오른쪽에 작은 패널이 붙습니다 (설정 > 일반/거래 > 거래 창 옆 정보 패널).
- **받을 낙찰금**(수금 연결 전 낙찰)과 아이템, 상대가 넣은 골드 비교: `✔ 낙찰금과 일치` / `부족 500골드` / `초과 200골드`
- **미지급 분배금**과 내가 넣은 골드 비교, **[분배금 입력]**: 남은 분배금을 내 골드 칸에 넣습니다.
  클라이언트가 이 기능을 막으면 "골드 칸에 직접 입력하세요" 안내가 나옵니다.
- 애드온은 **거래를 절대 자동으로 수락하지 않습니다.** 금액을 확인하고 수락 버튼은 직접 누르세요.

### 4.12 골드 장부
총 경매액(예정), 실제 수금액, 기타 수입, 지출 총액, 실제 지급액, 미지급금, 장부 잔액, 분배 예정액, 미연결 수금을 보여 줍니다.
- 장부 항목은 공대 목적 거래에서 자동 생성되며, 거래를 고치면 장부도 함께 바뀝니다.
- 거래 창을 거치지 않은 골드(예: 우편)는 **수동 수입/지출 기록**으로 사유와 함께 남깁니다. 수동 기록만 수정/취소할 수 있고 이력이 남습니다.
- **장부 내보내기(CSV)**

### 4.13 골드 정산
1. **정산 만들기** – 세션 참가자가 분배 대상으로 들어갑니다. (**참가자 동기화**로 새 인원 추가)
2. 왼쪽 설정: 분배 단위(코퍼/실버/골드 절사), 잔돈 처리(보관/다음 정산 이월/공대장 지급), 공대장 수수료(%·고정), 예비금(%·고정),
   탱커/힐러 추가 보상, 이월 잔돈 포함, 운영비·기타 공제 항목. **모든 값의 기본은 0, 기본 분배는 전원 균등**입니다.
3. 분배표 행 더블클릭: 분배 대상 포함/제외, 파티, 역할, 분배 비율(%), 비율 추가 지급(%), 고정 추가 지급, 수동 지정 금액
4. 정산은 **실제 수금 기준**입니다. 수금 거래가 연결된 낙찰금만 분배 가능 금액에 들어갑니다 (예상 정산 없음).
5. **정산 확정(잠금)** – 미연결 수금/미분류 거래 등이 있으면 경고 후 확정. 확정 시 공대원별 **분배 의무**가 만들어지고 보고서가 버전으로 저장됩니다.
6. **지급 거래 연결** – 공대원에게 거래로 골드를 준 뒤 연결합니다. 공대장 본인 몫은 거래 없이 지급 처리합니다.
   한 번의 거래 금액을 파티원 여러 명에게 나눠 연결할 수 있지만(대표 수령), 연결 합계는 거래 금액을 넘을 수 없습니다.
7. 파티별 인원·총액·지급 완료/미지급 인원·남은 금액이 아래에 표시됩니다.
8. **검증**: 총수입·공제·분배 인원·개인별 분배액·지급 완료·미지급금·최종 잔액 체크리스트
9. **정산 종료** – 미지급금/미환불이 남아 있으면 경고 후 "미결 항목 있음"으로 종료하고 기록은 그대로 유지됩니다.
10. 수정이 필요하면 **잠금 해제**(사유) → 수정 → 다시 확정. 기존 지급 기록은 유지되며 보고서 버전이 올라갑니다.
- 보고서: **간략 보고서**(채팅/복사), **상세 보고서**, **디스코드**(코드 블록), **이력**(버전별)
- 분배 지급 거래 때는 거래 창 정보 패널의 **[분배금 입력]** 을 쓰면 남은 금액을 정확히 넣을 수 있습니다.

### 4.14 설정
- **일반/거래**: 거래 자동 기록, 화면 알림, 채팅 기록, 분류 창, 연결 제안, 거래 창 정보 패널, 미니맵 버튼,
  공대장 HUD 표시/위치 잠금/지휘 명령 버튼, 창 배율/위치, 야영지 대체 인정, 버프 키워드 보완, 전투 준비 기준, 전멸 복구 창
- **경매/정산**: 기본 시작가/증가액/시간, 막판 연장, 공지 채널, 채팅 입찰 인식/채널, 공대원 입찰만 인정, 공지 옵션,
  자동 낙찰 확정(기본 꺼짐), 카운트 초, 연속 경매/대기 초, 정산 기본 단위/잔돈 처리, 이월 잔돈, 보고서 채널
- **데이터 관리**: 백업 목록(자동 하루 1회 + 정산 확정/복구 전 자동), 지금 백업, 백업 검증, 백업으로 복구,
  CSV 내보내기, 전체 백업 문자열(체크섬 포함) 내보내기/검증/복원, 설정 내보내기/가져오기, **공유 문자열 가져오기**
- **진단**: **자가 진단**(환경·API·이벤트·거래 기록·저장 데이터 무결성·정산 잔액·오류 기록을 한 번에 점검해 복사, `/brl 진단`),
  무결성 상세, 오류 기록, 거래 이벤트 추적, 이 클라이언트의 API/이벤트 지원 목록

### 4.15 공대장 HUD
메인 창을 닫아 둔 채로 쓰는 작은 창입니다 (`/brl hud`, 대시보드 [HUD], 단축키, 설정 > 일반 > 공대장 HUD 표시).
- 진행 현황: 경매(최고 입찰·남은 시간/카운트), 거래 상대에게서 받을 낙찰금·줄 분배금, 휴식 남은 시간, 풀링 판정, 도핑, 분배 미지급
- 경매 버튼: **카운트 / 카운트 취소 / 다음 경매 / 메인 창**
- 지휘 명령 버튼(지휘 명령은 HUD 에만 있음, 풀링 초·휴식 분은 전투 지휘 > 공지·명령 탭에서 설정): **준비 확인 · 풀링 N초 · 풀링 취소 · 풀링 판정 / 공격 중지 · 후퇴 · 재정비 · 공략 안내 / 전투 준비 · 휴식 N분(누르면 휴식 종료로 바뀜)**
- 제목줄 **[지휘 ▾]** 로 지휘 버튼을 접고 펼 수 있고, 위치는 드래그로 옮기며 설정에서 잠글 수 있습니다.

## 5. 공대장 전용 / 권한

이 애드온은 **공격대장 한 명만 설치해서 쓰는 애드온**입니다. 부공대장·공대원 화면과 애드온 간 통신 기능은 없습니다.

| 상태 | 할 수 있는 일 |
|---|---|
| 공격대장 (그룹 안) | 모든 기능 |
| 그룹 밖 (혼자) | 사전 준비(경매 등록·편성 계획·공략 편집 등)와 공격대 해산 후 정산·지급 기록. 세션을 만든 캐릭터만 그 세션 장부를 수정 |
| 부공대장 / 공대원 | 모든 운영 기능 잠김 (화면 오른쪽 위 "공대장 권한 없음 · 편집 잠김"). 내 데이터 열람·백업만 가능 |

- 공대장 권한을 잠시 넘기면 그동안 편집이 잠기고, 다시 받으면 재개됩니다. 그 사이의 거래도 자동 기록은 계속됩니다.
- 권한 정보를 읽을 수 없으면(Secret Value) 안전을 위해 편집이 잠깁니다.

## 6. 자주 묻는 질문

**Q. 거래했는데 "확인 불가"로 기록되었습니다.**
아이템만 오간 거래에서 완료 메시지를 받지 못했거나, 거래 중 UI 재시작이 있었던 경우입니다. 가방/골드를 직접 확인한 뒤
거래 로그 우클릭 > **수동 확인**을 하면 합산됩니다. 실제로 취소된 거래면 **취소로 표시**하세요.

**Q. 낙찰 금액과 같은 금액을 받았는데 자동으로 수금 처리되지 않습니다.**
의도된 동작입니다. 금액이 같아도 다른 목적의 거래일 수 있어 **제안만** 합니다. 분류 창의 **제안대로 연결** 또는 거래 로그에서 승인하세요.

**Q. 우두머리 전투 중 공지가 바로 나가지 않습니다.**
포에버(12.x API)는 우두머리 전투 중 애드온의 채팅 전송을 제한합니다. 메시지는 대기열에 보관되었다가 제한이 풀리면 자동 전송됩니다.

**Q. 아이템만 오간 거래도 정확히 기록되나요?**
수락 시점에 가방 수량을 기록해 두었다가 거래 후 수량 변화를 비교합니다. 완료 메시지를 놓쳐도 가방 변화가 정확히 일치하면 완료로,
변화가 없으면 취소로 판정합니다. 같은 아이템을 같은 수만큼 주고받는 등 판별할 수 없으면 기존처럼 완료 메시지로만 판정합니다.

**Q. 징표 버튼이 동작하지 않습니다.**
징표 지정은 공대장/부공대장만 가능하며 대상이 있어야 합니다. 징표 바는 전투 전에 열어 두어야 합니다.
