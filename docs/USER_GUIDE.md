# BIG RAID LEADER 사용 설명서

월드 오브 워크래프트: 포에버 공격대장 전용 통합 애드온 **BIG RAID LEADER(빅 레이드 리더)** 의 설치 방법과 기능별 사용법입니다.

---

## 1. 설치

### 1.1 설치 순서
1. 배포 ZIP(`BigRaidLeader-1.0.0.zip`)의 압축을 풉니다. 안에 `BigRaidLeader` 폴더가 하나 있습니다.
2. 배틀넷 앱에서 포에버를 선택 → 옵션(톱니바퀴) → **탐색기에서 보기**로 설치 폴더를 엽니다.
3. 설치 폴더 안의 `Interface\AddOns\` 에 `BigRaidLeader` 폴더를 넣습니다. (폴더가 없으면 만드세요)
   - 올바른 위치: `…\Interface\AddOns\BigRaidLeader\BigRaidLeader.toc`
   - 잘못된 위치: `…\Interface\AddOns\BigRaidLeader\BigRaidLeader\BigRaidLeader.toc` (폴더가 한 번 더 들어간 경우)
4. 게임을 시작하고 캐릭터 선택 화면 왼쪽 아래 **애드온** 버튼에서 `BIG RAID LEADER` 를 켭니다.
5. 접속 후 채팅창에 `[BRL] v1.0.0 로드됨` 메시지가 보이면 설치 완료입니다.

### 1.2 "오래된 애드온"으로 표시될 때
TOC 의 Interface 번호(16001)가 클라이언트와 다르면 오래된 애드온으로 표시됩니다.
- 애드온 목록에서 **오래된 애드온 불러오기**를 체크하거나,
- 게임에서 `/run print(select(4, GetBuildInfo()))` 를 입력해 나온 숫자로 `BigRaidLeader.toc` 첫 줄 `## Interface:` 값을 바꿉니다.

### 1.3 데이터 위치
데이터는 로그아웃/UI 재시작(`/reload`) 시 `WTF\Account\<계정>\SavedVariables\BigRaidLeader.lua` 에 저장됩니다.
게임이 비정상 종료되면 마지막 저장 이후 기록이 사라질 수 있으니, 정산 직후 `/reload` 를 한 번 해 두면 안전합니다.

## 2. 기본 사용

| 동작 | 방법 |
|---|---|
| 메인 창 열기/닫기 | `/brl`, 미니맵 버튼 좌클릭, 단축키(키 설정 > 애드온 > BIG RAID LEADER) |
| 경매 화면 바로 열기 | 미니맵 버튼 우클릭, `/brl 경매` |
| 메뉴 바로 열기 | `/brl 정산`, `/brl 거래`, `/brl 편성` … |
| 창 이동/크기 | 제목 표시줄 드래그 / 오른쪽 아래 모서리 드래그 |
| 도움말 | `/brl 도움말` |

### 2.1 화면 구성
- **제목 표시줄**: 현재 **공격대 세션** 선택, 내 권한(공대장/부공대장/공대원), 전투 중 표시
- **왼쪽 메뉴**: 15개 메뉴. `거래 로그` 옆 숫자는 확인이 필요한 거래 수, `전리품 경매` 옆 "진행"은 경매 진행 중
- **아래 상태 표시줄**: 진행 중인 거래, 채팅 제한 상태, 확인 불가 거래 수

### 2.2 공격대 세션
경매·거래 연결·장부·정산은 **공격대 세션** 단위로 관리합니다.
- 제목 표시줄 드롭다운 → **+ 새 공격대 세션** (공격대 선택 + 이름)
- 경매 아이템을 처음 등록할 때 세션이 없으면 자동으로 만들어집니다.
- 세션에는 그 시간 동안 공격대에 있었던 **참가자**가 자동 기록되며, 정산 분배 대상의 기본값이 됩니다.
- 세션을 만든 캐릭터가 그 세션 장부의 최종 책임자입니다.

### 2.3 슬래시 명령
```
/brl                      메인 창
/brl <메뉴>               대시보드 모집 공대원 편성 역할 준비 버프 지휘 공략 경매 거래 장부 정산 통계 설정
/brl 경매 [링크] [시작가]   경매 등록 (예: /brl 경매 [천둥분노] 500)
/brl 입찰 <이름> <금액>     진행 중인 경매에 수동 입찰
/brl 준비                  준비 확인
/brl 풀 [초]               풀링 카운트다운
/brl 세션 [이름]           새 공격대 세션
/brl 백업                  데이터 백업
/brl 검사                  데이터 무결성 검사
/brl 호환성                 API 지원 여부 확인
```

### 2.4 금액 입력 방법
금액 칸에는 다음 형식을 모두 쓸 수 있습니다. 내부 계산은 모두 **정수 코퍼**(1골드 = 10,000코퍼)입니다.
- `2500` → 2,500골드 / `2,500` → 2,500골드
- `2500g 30s 5c`, `2500골드 30실버 5코퍼`
- `2.5k` → 2,500골드 / `3천` → 3,000골드 / `1.2만` → 12,000골드

## 3. 골드팟 운영 흐름 (권장 순서)

1. **세션 만들기** – 공격대 시작 시 새 세션 (공격대 종류 선택)
2. **경매 등록** – 전리품 경매 > 아이템 등록 (Shift+클릭, 드래그, 전리품 창에서 가져오기)
3. **경매 진행** – 다음 경매 시작 → 공대원은 공격대 채팅에 금액만 입력 → 마감 → **낙찰 확정**
4. **수금** – 낙찰자와 거래 (아이템을 건네고 골드를 받음) → 거래 직후 분류 창에서 **제안대로 연결** 또는 **경매금 수금**
5. **미수금 확인** – 낙찰·수금 탭 / 골드 장부에서 미수금 0 확인
6. **정산** – 골드 정산 > 정산 만들기 → 설정(운영비/수수료 등) 확인 → **정산 확정(잠금)**
7. **분배 지급** – 공대원과 거래로 골드 지급 → 분류 창에서 **분배 지급** 연결 (또는 정산 화면 > 지급 거래 연결)
8. **보고서** – 간략 보고서 채팅 출력, 디스코드용 복사
9. **정산 종료** – 미수금/미지급금 0 확인 후 정산 종료 (남아 있으면 경고 후 기록 유지)

## 4. 기능별 사용 방법

### 4.1 대시보드
공격대 이름·인원·탱커/힐러/딜러 수·부족한 역할·준비 확인·현재 보스·진행률·경매 총액·실제 수금액·미수금·분배 가능 골드·
미지급금·정산 상태·장부 잔액·확인 필요 거래·파티별 인원을 타일로 보여 줍니다. **타일을 클릭하면 해당 화면으로 이동**합니다.
아래 **빠른 실행**에서 준비 확인, 풀링, 버프 점검, 다음 경매 시작, 징표 바 등을 바로 실행합니다.
오른쪽 **내 정보**는 공대원 입장에서 자신의 파티·역할·임무·공지·현재 경매·분배 예정액을 보여 줍니다.

### 4.2 공격대 모집
- 공격대 선택 → 역할별/직업별 **모집 정원** 입력 → 모집 문구 편집 (치환: `{raid}` `{size}` `{have}` `{need}` `{roles}` `{note}`)
- 채널(길드/일반/외치기/참여 중인 채널) 선택 후 **모집 문구 전송** – 게임 정책상 클릭할 때마다 한 번만 전송됩니다.
- 모집 중에는 귓속말("1", "참", "힐 가능", "법사" 등)을 보낸 사람이 **지원자 대기열**에 자동 추가됩니다.
  직업/역할 키워드를 자동 인식하고, 같은 사람이 다시 보내면 "중복"으로 표시합니다.
- 지원자 선택 → **승인(초대)** / 거절 / 보류 / 삭제. 초대는 버튼 클릭으로만 이루어집니다.
- **모집 종료 공지**로 마감, 공대원이 빠지면 재모집 안내가 표시됩니다. 자주 쓰는 설정은 템플릿으로 저장하세요.

### 4.3 공대원 관리
현재 공대원의 파티·이름(공대장/부공대장 표시)·직업·레벨·역할·접속/자리비움/사망·임무를 보여 줍니다.
검색, 파티/직업/역할/이름 정렬(열 제목 클릭), 역할 필터를 지원합니다.
아래 버튼으로 **역할 지정**(탱커/힐러/근접/원거리)과 **파티 변경**을 합니다. 역할을 지정하지 않으면 직업 기준 "추정"으로 표시됩니다.
탱커/힐러 부족, 인원 부족, 중복 임무 배정 경고가 아래에 표시됩니다.

### 4.4 파티 편성
- 8개 파티 × 5칸. **이름을 클릭한 뒤 다른 칸을 클릭**하면 이동/교체됩니다. 드래그 앤 드롭도 됩니다.
- 우클릭: **고정(*)** – 자동 편성 시 현재 파티 유지 / 편성에서 제외
- **자동 편성 제안**: 탱커 분산, 힐러 균등, 근접/원거리 묶음, 주술사·성기사·드루이드 등 버프 공급원 분산, 고정 인원을 고려한
  제안을 미리 보여 줍니다. **제안 채택**을 눌러야 계획에 반영됩니다.
- **공격대에 적용**: 계획대로 실제 파티를 한 명씩 이동합니다. 전투 중에는 실행되지 않고, 적용 중 전투가 시작되면 중단됩니다.
- 현재 편성 복사, 초기화, 채팅 출력, 템플릿 저장/불러오기. 보스별 배치는 `보스:<이름>` 처럼 이름을 붙여 템플릿으로 저장하세요.

### 4.5 역할 배정
- 위쪽에서 **전술표**(기본 또는 보스별)를 고릅니다.
- **전술 임무** 13종: 메인/보조/추가 탱커, 탱커 전담 힐러, 파티 담당 힐러, 전체 치유, 차단, 해제, 군중제어, 특정 몬스터 처리,
  보스 기믹, 풀링, 특수 기술. 임무를 선택(또는 더블클릭) → **담당자 추가** (메모: 대상/위치)
- **전술 순서표**: 차단/해제/탱커 교대/생존기/특수 기믹 순서와 **예비 담당자**. ▲▼로 순서 변경.
- **담당자 교체**: 한 사람을 모든 임무와 순서표에서 다른 사람으로 바꿉니다.
- 아래에 중복 배정(예: 메인 탱커 + 전체 치유)과 공대원이 아닌 담당자 경고가 표시됩니다.
- **전술표 채팅 출력**, **공대원에게 임무 전송**(애드온 설치 공대원에게 본인 임무만 전송), 전술표 저장/불러오기.

### 4.6 준비 상태
- **준비 확인 시작** → 준비 완료/준비 안 됨/미응답/오프라인, 사망, 인스턴스 미입장, 내구도를 표시합니다.
- 내구도: 본인은 장비 기준, 다른 공대원은 애드온 설치자가 보낸 보고 기준입니다.
- 마법부여·저항 장비·시약·탄약·물약·장비 착용은 게임 API로 다른 사람 상태를 볼 수 없어 **수동 점검** 항목입니다.
  행을 더블클릭해 항목을 체크하거나, **전원 항목 체크**를 사용합니다.
- **결과 채팅 출력**으로 미응답/사망/미입장/내구도 낮음 인원을 알립니다.

### 4.7 버프 및 야영지
- **버프 점검** 탭: 공대원별 직업 버프·음식·영약·비약 여부를 표시합니다. `O`=있음, `야영`=야영지 효과로 대체, `X`=필수 누락,
  노란색=곧 만료. 전투 중에는 점검할 수 없습니다. 전멸 후에는 재도핑 점검 안내가 표시됩니다.
- **야영지 효과** 탭: 포에버 야영지 시설(숫돌 바퀴, 어항, 마나 우물, 마법 류트, 야영 의자, 향초, 구급 상자, 진영 깃발)과
  대체되는 직업 버프, 준비 여부, 담당자, 보스별 필요 여부, 적용 인원 확인 결과를 관리합니다.
- **필수 버프/담당자** 탭: 공통 필수 버프, 보스별 필수 버프(오른쪽 위에서 보스 선택), 버프 담당자 지정/자동 지정.
- 포에버의 실제 버프 이름이 다르면 **설정 > 일반 > 버프 키워드 보완**에서 이름을 추가하세요.

### 4.8 전투 지휘
- **지휘 명령**: 준비 확인, 풀링 카운트다운(공식 카운트다운, 미지원 시 채팅 카운트다운), 풀링 취소, 공격 중지, 후퇴,
  전투 재정비, 휴식 시작(종료 1분 전 알림)/종료, 보스 공략 안내. 커스텀 공지(공격대 경보/공격대/파티/길드),
  **명령 저장** 후 더블클릭 실행, **애드온 공지**(설치 공대원 화면에 표시).
- 단축키: 게임 메뉴 > 키 설정 > 애드온 > BIG RAID LEADER (창 열기, 준비 확인, 풀링, 풀링 취소, 경매 화면)
- **징표** 탭: 징표별 담당 몬스터/차단 담당/군중제어 담당/메모 규칙을 만들고 채팅으로 출력합니다(`{rt8}` 아이콘 포함).
  보스를 선택하면 보스별 징표 템플릿이 됩니다.
- **징표 바 열기/닫기**: 해골·엑스·별·동그라미·다이아몬드·세모·달·네모 버튼과 대상 징표 해제, 월드 징표 1~8과 전체 해제.
  포에버(12.x API)에서는 징표 지정이 보호 기능이라 이 버튼을 **직접 클릭**해야 합니다. 전투 중에는 징표 바를 열고 닫을 수 없으니
  전투 전에 열어 두세요.
- **전술 메모** 탭: 공대장 개인 메모(비공개), 공격대 공유/탱커/힐러/딜러/단계별 메모. `★` 또는 `!` 로 시작하는 줄은 강조됩니다.
  템플릿 삽입, 채팅 출력, 복사, 애드온 공유.

### 4.9 보스 공략
- 왼쪽에서 공격대(지하 심굴 10인 / 하이잘 정상 20인 / 오닉시아의 둥지 40인 / 사용자 지정)와 보스를 고릅니다.
  - ✔ = 처치, ▶ = 현재 보스, ? = 미확인 정보
- **공략** 탭: 개요, 주요 기술, 전투 단계, 탱커/힐러/딜러 주의사항, 차단·해제·군중제어 대상, 위험 요소, 추천 진형, 메모, 전리품.
  **항목 편집/기술 추가/단계 추가/이름 변경**으로 직접 채우고, **공략 안내 출력**으로 공유합니다.
- **배치도** 탭: 단계별 배치도. 종류(탱커/힐러/근접/원거리/파티/공대원/보스/위험 구역/담당 구역/이동 경로/징표)와 이름을 정해
  **배치 추가** → 드래그로 이동, 우클릭 삭제. 기본/산개 진형 템플릿, 파티별 배치, 이전 단계 복사, 9구역 텍스트로 채팅 공유.
- **타임라인** 탭: 예상 기술/생존기/탱커 교대/단계 지침을 시각(초)과 함께 등록. **타이머 시작/다음 단계/정지/초기화**는 공대장이 직접
  진행하며, 우두머리 전투 시작 이벤트가 오면 자동으로 시작됩니다. 알림은 화면에만 표시됩니다(전투 중 채팅 제한).
- **진행** 탭: 시도/전멸/처치 횟수, 처치 시각/시간, 최근 전투 기록, 재시도 전략과 다음 시도 수정사항 메모.
  우두머리 전투 시작/종료 이벤트로 자동 기록되며, 수동 기록도 가능합니다.
- 지하 심굴/하이잘 정상의 공식 우두머리 정보는 공개되지 않았습니다. 처음 전투할 때 **현재 보스**로 지정해 두면, 게임이 알려주는
  우두머리 이름으로 자동 갱신됩니다.

### 4.10 전리품 경매
**골드 경매 탭**
- 아이템 등록: **아이템 등록** 버튼(시작가/최소 증가액/즉시 낙찰가/시간), 아래 입력칸에 Shift+클릭 후 Enter,
  **전리품 창에서**(전리품 창이 열려 있을 때). 같은 아이템 중복 등록 시 확인을 받습니다.
- 대기열: ▲▼ 순서 변경, 시작(또는 더블클릭), 수정, 취소, 재경매(유찰/취소/낙찰 취소 건)
- 진행: **다음 경매 시작** → 공격대 경보로 시작 공지 → 공대원은 **금액만** 입력(`1500`, `1500골드`, `1.5k`, `입찰 1500`)
  - 최소 입찰가 미달, 같은 금액(먼저 입찰한 사람 우선), 공대원이 아닌 사람의 입찰은 거부되어 입찰 내역에 사유와 함께 남습니다.
  - 귓속말 입찰이 거부되면 사유를 귓속말로 알려 줍니다.
  - 마감 5초 전 카운트다운, 막판 입찰 연장(설정), 즉시 낙찰가 도달 시 자동 마감
- **낙찰 확정**: 마감 후 공대장이 확인하고 확정합니다. **다른 입찰로 낙찰**, **입찰 철회**, 유찰, 경매 취소 가능.
- 우두머리 전투 중(채팅 제한)에는 채팅 입찰을 인식할 수 없으니 **수동 입찰**을 사용하세요.

**낙찰·수금 탭**
- 낙찰별 낙찰액·수금·미수금·상태(미수금/부분 입금/완납/초과 입금/환불 필요)·아이템 전달 여부
- **수금 거래 연결**(또는 더블클릭): 완료된 거래를 골라 금액을 연결 → 부분 입금, 여러 거래 합산, 다른 사람의 대리 입금 가능.
  미수금보다 크면 초과 입금 경고 후 기록합니다.
- **연결 내역/해제**, 전달 표시, 금액 수정(사유), **낙찰 취소**(이미 받은 금액은 환불 필요로 표시) → 환불 거래를 연결하면 정리됩니다.
- 미수금 안내, 결과 공지

**기타 분배 방식 탭**: 주사위(자동 집계, 첫 주사위만 인정, 동점 표시), DKP(입찰/차감/조정/전원 지급), EPGP(EP 지급, GP 부과,
PR 계산, 감쇠), Loot Council(투표), 우선순위 목록, 수동 분배. 분배 취소/수령자 변경 시 점수가 자동 환원됩니다.
같은 아이템의 중복 분배를 막습니다.

### 4.11 거래 로그
- 내 캐릭터의 모든 거래가 자동 기록됩니다: 시각, 거래 상대, 받은 골드, 지급 골드, 아이템, 거래 목적, 연결, 상태
- **상태**: 완료 확인 / 확인 불가 / 취소 / 수동 확인 / (수동 조정) / 기록 취소. **완료 확인·수동 확인만** 금액에 합산됩니다.
- **거래 목적**: 경매금 수금, 공대원 골드 분배, 공대장 개인 거래, 기타 공대 지출, 기타 공대 수입, 경매금 환불, 분류되지 않은 거래.
  개인 거래와 미분류 거래는 공대 장부에 들어가지 않습니다.
- 필터: 골드팟 관련/개인/확인 불가/미분류/취소, 입금/출금, 골드/아이템 거래, 기간(오늘/7일/30일/현재 세션), 거래 상대, 메모/아이템 검색
- 우클릭(작업 메뉴): 상세/수정 이력, 목적 변경, 경매금/분배/환불 연결, **연결 제안 승인**, **수동 확인**(확인 불가 거래를 직접 확인했을 때만),
  취소로 표시, **금액 정정**(원본은 보존, 사유 필수), 메모, 기록 취소/복원
- **수동 기록 추가**: 자동 기록되지 않은 거래를 사유와 함께 추가합니다. 수동 기록은 자동 기록과 구분됩니다.
- **거래 직후 분류 창**: 거래가 완료되면 작은 창이 떠서 한 번의 클릭으로 경매금 수금/분배 지급/개인/기타 수입·지출로 분류합니다.
  낙찰자와의 거래이면 "제안: ○○ 낙찰금 … (금액 일치)" 처럼 제안이 표시되며, **제안대로 연결**을 눌러야 반영됩니다.
- 거래 완료 귓속말(설정에서 켬): `[BIG RAID LEADER 거래 완료] 상대방 / 아이템 / 받은 골드 / 거래 시각`

### 4.12 골드 장부
총 경매액(예정), 실제 수금액, 미수금, 기타 수입, 지출 총액, 실제 지급액, 미지급금, 장부 잔액, 분배 예정액, 미연결 수금을 보여 줍니다.
- 장부 항목은 공대 목적 거래에서 자동 생성되며, 거래를 고치면 장부도 함께 바뀝니다.
- 거래 창을 거치지 않은 골드(예: 우편)는 **수동 수입/지출 기록**으로 사유와 함께 남깁니다. 수동 기록만 수정/취소할 수 있고 이력이 남습니다.
- **장부 내보내기(CSV)**

### 4.13 골드 정산
1. **정산 만들기** – 세션 참가자가 분배 대상으로 들어갑니다. (**참가자 동기화**로 새 인원 추가)
2. 왼쪽 설정: 분배 단위(코퍼/실버/골드 절사), 잔돈 처리(보관/다음 정산 이월/공대장 지급), 공대장 수수료(%·고정), 예비금(%·고정),
   탱커/힐러 추가 보상, 이월 잔돈 포함, 운영비·기타 공제 항목. **모든 값의 기본은 0, 기본 분배는 전원 균등**입니다.
3. 분배표 행 더블클릭: 분배 대상 포함/제외, 파티, 역할, 분배 비율(%), 비율 추가 지급(%), 고정 추가 지급, 수동 지정 금액
4. 오른쪽 위 **확정 정산(실제 수금)** / **예상 정산(전원 완납 가정)** 전환. 실제로 받지 않은 골드는 확정 정산에 포함되지 않습니다.
5. **정산 확정(잠금)** – 미수금/미연결 수금/미분류 거래 등이 있으면 경고 후 확정. 확정 시 공대원별 **분배 의무**가 만들어지고 보고서가 버전으로 저장됩니다.
6. **지급 거래 연결** – 공대원에게 거래로 골드를 준 뒤 연결합니다. 공대장 본인 몫은 거래 없이 지급 처리합니다.
   한 번의 거래 금액을 파티원 여러 명에게 나눠 연결할 수 있지만(대표 수령), 연결 합계는 거래 금액을 넘을 수 없습니다.
7. 파티별 인원·총액·지급 완료/미지급 인원·남은 금액이 아래에 표시됩니다.
8. **검증**: 총수입·미수금·공제·분배 인원·개인별 분배액·지급 완료·미지급금·최종 잔액 체크리스트
9. **정산 종료** – 미수금/미지급금이 남아 있으면 경고 후 "미결 항목 있음"으로 종료하고 기록은 그대로 유지됩니다.
10. 수정이 필요하면 **잠금 해제**(사유) → 수정 → 다시 확정. 기존 지급 기록은 유지되며 보고서 버전이 올라갑니다.
- 보고서: **간략 보고서**(채팅/복사), **상세 보고서**, **디스코드**(코드 블록), **이력**(버전별)
- **분배액 안내**: 애드온 설치 공대원에게 본인의 분배 예정액과 지급 상태만 귓속말로 보냅니다.

  CSV 내보내기, 전체 백업 문자열(체크섬 포함) 내보내기/검증/복원, 설정 내보내기/가져오기, 오류 기록
- **호환성**: 이 클라이언트에서 사용 가능한 API/이벤트 목록 (문제 발생 시 결과 복사)
- **정책 안내**: 골드팟 정책 확인

## 6. 자주 묻는 질문

**Q. 거래했는데 "확인 불가"로 기록되었습니다.**
아이템만 오간 거래에서 완료 메시지를 받지 못했거나, 거래 중 UI 재시작이 있었던 경우입니다. 가방/골드를 직접 확인한 뒤
거래 로그 우클릭 > **수동 확인**을 하면 합산됩니다. 실제로 취소된 거래면 **취소로 표시**하세요.

**Q. 낙찰 금액과 같은 금액을 받았는데 자동으로 수금 처리되지 않습니다.**
의도된 동작입니다. 금액이 같아도 다른 목적의 거래일 수 있어 **제안만** 합니다. 분류 창의 **제안대로 연결** 또는 거래 로그에서 승인하세요.

**Q. 우두머리 전투 중 공지가 바로 나가지 않습니다.**
포에버(12.x API)는 우두머리 전투 중 애드온의 채팅/애드온 메시지 전송을 제한합니다. 메시지는 대기열에 보관되었다가 제한이 풀리면 자동 전송됩니다.

**Q. 징표 버튼이 동작하지 않습니다.**
