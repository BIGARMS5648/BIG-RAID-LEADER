# BIG RAID LEADER (빅 레이드 리더) v2.3.0

월드 오브 워크래프트: 포에버 공격대장 전용 통합 애드온입니다.

## 설치
이 `BigRaidLeader` 폴더를 포에버 클라이언트 설치 폴더의 `Interface\AddOns\` 안에 넣으세요.
올바른 위치: `Interface\AddOns\BigRaidLeader\BigRaidLeader.toc`

## 사용
- `/brl` : 메인 창 열기/닫기 (미니맵 동전 버튼으로도 열 수 있음)
- `/brl 도움말` : 명령어 목록
- `/brl hud` : 공대장 HUD (경매/카운트, 거래 상대, 풀링 판정, 도핑 + 지휘 명령 버튼)
- 키 설정 > 애드온 > BIG RAID LEADER : 단축키

## 핵심 흐름
공격대 세션 만들기 → 전리품 경매 → 낙찰 확정 → 낙찰자와 거래(자동 기록) → 수금 연결 →
골드 정산 확정 → 공대원에게 거래로 지급 → 지급 연결 → 정산 보고서 → 정산 종료

자세한 사용 설명서, API 호환성, 테스트 결과, 문제 해결 가이드는 프로젝트 저장소의 `docs/` 와 문서 파일을 참고하세요.
https://github.com/BIGARMS5648/BIG-RAID-LEADER

※ 공격대장 전용 애드온입니다. 공대장이 아닐 때는 운영 기능이 잠깁니다.
※ 실제 포에버 클라이언트에서의 검증은 아직 진행되지 않았습니다. 문제가 있으면 `/brl 진단` (설정 > 진단 > 자가 진단)
결과와 `/brl 추적` (최근 거래 이벤트) 내용을 함께 알려 주세요.
※ 골드 경매(GDKP)는 지역별 블리자드 정책을 확인한 뒤 운영하세요.
